# Finance Tracker

Трекер для учета доходов и расходов пользователя. Помогает следить за финансовыми потоками и распределять средства рациональнее. Позволяет устанавливать бюджет как общий, так и на отдельные категории, а при скором его окончании будет предупреждать пользователя о возможном превышении лимита.

## Идея проекта

Приложение поможет наглядно посмотреть, куда уходят и как приходят деньги. С его помощью легче планировать будущие расходы, составлять бюджет и анализировать свои статьи затрат. Контроль денежных потоков поможет распределять средства рационально.
Пользователь сможет добавлять свои статьи расходов и доходов, сортировать их по категориям и для каждой устанавливать бюджет, который также будет суммироваться в один общий.
Приложение будет показывать средние траты за день по категориям, месяцам, самые затратные категории. Позволит сравнивать графики денежных потоков за различный период.

## Используемые библиотеки

- **Streamlit** — библиотека для создания пользовательского интерфейса. Позволит сделать формы добавления расходов и доходов, таблицы транзакций и фильтры по категориям и периодам.
- **SQLite (`sqlite3`)** — библиотека для работы с локальной базой данных. Будет хранить транзакции, категории, бюджеты и историю изменений.
- **Pandas** — библиотека для обработки табличных данных. Будет использоваться для группировки расходов по категориям, расчёта среднего расхода в день, сравнения месяцев и подготовки данных для графиков.
- **Plotly** — библиотека для визуализации данных. Нужна для построения графиков расходов по категориям, времени и бюджету.

## Итерация 1

- **Учёт операций:** добавление и удаление транзакции с указанием категории, суммы и даты.
- **База данных:** сохранение истории транзакций в локальной базе данных SQLite.
- **Установка бюджета:** возможность задать бюджет на месяц для выбранных категорий и просмотр текущего остатка.

## Итерация 2

- **Интерактивные графики (Plotly):** визуализация распределения расходов по категориям.
- **Базовая аналитика (Pandas):** расчет среднего расхода в день и вывод самых затратных категорий.
- **Уведомления о лимитах:** автоматическое предупреждение пользователя в интерфейсе, если расходы по категории приближаются к заданному бюджету или превышают его.
